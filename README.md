# 🔋 AI-Battery-Management-System

An unsupervised Machine Learning-driven Predictive BMS dashboard designed for electric vehicle battery packs to track cell performance and ensure operational safety.

## 🛠️ Core Engineering Features
* **Predictive Diagnostics:** Implements dynamic 3-Sigma statistical outlier detection to flag anomalous single-cell thermal trajectories.
* **Sensing Circuitry Simulation:** Validates core inputs representing shunt resistor current data and thermistor temperature readings.
* **State Estimation:** Architected for real-time State of Charge (SOC) and State of Health (SOH) tracking models.
* **Fault Handling:** Features robust edge-case tracking specifically built to catch Open Circuit and Zero Voltage failures safely.

## 💻 Technical Architecture
* **Language:** JavaScript, Python
* **Keywords:** Unsupervised ML, Predictive Maintenance, BMS Logic, Thermal Safety.
